# 懒人封面 V1.2 重构设计

## 目标

在不削弱公开免费 Skill 实用性的前提下，降低入口上下文占用、消除相互冲突的规则，并提高提示词的真实性、文字成功率和跨平台稳定性。

公开 Skill 继续交付封面设计提示词，不承担 LazyCover Pro 的直接生图、三候选排名、持久化偏好、Series Style Profile、私有行业策略、实验权重或付费交付能力。

## 方案

采用渐进式披露结构：`SKILL.md` 只保留触发边界、Fast/Standard 两种流程、共享决策顺序、输出契约和参考资料路由。平台规格、内容分析、七类风格、模型适配与质量检查分别进入 `references/`，只在当前任务需要时读取。

不继续增加风格数量。V1.2 优先稳定已有七类风格，并将重复、过度绝对化或互相矛盾的规则改成有范围的决策条件。

## 关键行为

- Fast Mode 在信息足够时不追问，直接输出一份可用提示词。
- Standard Mode 先展示一张简短的设计决策卡，得到确认后输出提示词。
- 多平台请求分别生成平台适配结果，不复用一份所谓通用提示词。
- 风格由内容需求优先决定；行业关键词只是先验，不再强制 `AI -> 科技风`。
- Logo 支持左上、右上、左下、右下四个预设角位，由冲突最少原则推荐。
- 对截图、Logo、人物、数字和产品参数实施事实来源保护；未提供或未验证的证据不得伪造。
- 提供一体生图与后期排字两种文字模式。高密度文字默认建议后期排字。
- 最终输出前进行内部质检，并且最多自动修正一次，避免无限循环。

## 验收标准

1. `SKILL.md` 明显小于 V1.1 的 1208 行入口，并能独立完成模式路由。
2. 每份条件性参考资料都从入口或上游参考文件明确链接。
3. 不再存在跳号、五输入/六字段冲突、左下角禁用、AI强制科技风和全局禁止纯色背景等已知矛盾。
4. 包含事实保护、两种文字模式、多平台分开输出和输出前质量检查。
5. `quick_validate.py` 通过，元数据版本与 V1.2 保持一致。
6. 公开 Skill 中不出现 LazyCover Pro 的私有策略、排名权重或用户数据逻辑。
